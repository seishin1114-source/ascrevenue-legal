Revenue for App Store Connect

提供：みやじんプロダクト

App Store のダウンロード数と売上を、前の期間と比べて振り返る。

ご自身の App Store Connect API キーで、Apple の売上レポートを端末に直接取り込みます。開発者のサーバーはありません。鍵は端末のキーチェーンに、売上は端末の中にだけ保存します。

ダッシュボード

1日・7日間・今週・先週・今月・先月・指定期間のダウンロードと売上を、前の期間と比べて表示します。

分析

国別・アプリ別・種類別（新規・再ダウンロード・課金など）の内訳と推移。

マイページ

取り込んだ1年分の累計、過去最高の月、伸びたアプリと国をまとめて表示します。

デモ

API キーがなくても、架空のデータで全画面を試せます。
