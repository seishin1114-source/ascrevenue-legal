本利用規約（以下「本規約」）は、みやじんプロダクト（以下「当社」）が提供するアプリ「Revenue for App Store Connect」（以下「本アプリ」）の利用条件を定めるものです。ユーザーは、本アプリを利用することで本規約に同意したものとみなされます。

第1条（本アプリの目的）

  1. 本アプリは、ユーザーご自身の App Store Connect の売上レポートを読み取り、ダウンロード数と売上を表示・分析するための個人向けツールです。
  2. 本アプリは Apple Inc. が提供・承認・後援するものではなく、当社は Apple Inc. と提携関係にありません。Apple、App Store、App Store Connect は Apple Inc. の商標です。

  2. 本アプリは13歳未満の方の利用を想定していません。未成年者は保護者の同意のうえご利用ください。
  3. ユーザーは、ご自身が売上レポートを閲覧する権限を持つ App Store Connect のアカウントに限り、本アプリと接続できます。

第3条（API キーの作成と管理）

  1. 本アプリは、ユーザーが App Store Connect で作成した API キーを使って、売上レポートを読み取ります。本アプリが求める権限は「Sales and Reports（売上とレポート）」のロールだけです。本アプリから App Store Connect の設定やアプリの情報を変更することはありません。
  2. API キーの作成・保管・無効化は、ユーザーの責任で行ってください。端末を紛失した場合や、鍵が漏れたおそれがある場合は、App Store Connect の「ユーザとアクセス」→「統合」から鍵を無効にしてください。
  3. ユーザーは、Apple の利用規約（Apple Developer Program 使用許諾契約を含みます）を、ご自身の責任で遵守するものとします。
  4. 接続は、本アプリの「マイページ」→ 右上のメニューからいつでも解除できます。

第4条（表示される数値について）

  1. 本アプリに表示される数値は、Apple の売上レポート（日次の概要）から取得したものです。売上は推定の受取額であり、実際のお支払い額とは異なる場合があります。確定した金額は App Store Connect の「支払いと財務レポート」でご確認ください。
  2. 売上レポートの日付は太平洋時間です。日次のレポートは翌日以降に公開され、公開が遅れることや、後から変わることがあります。
  3. Apple に日次のレポートが残る期間の制限により、本アプリが取り込めるのは過去1年分です。累計等はその範囲の合計です。
  4. 表示通貨への換算は、本アプリに組み込んだ固定の換算表による目安です。実際の為替レートとは異なります。
  5. 前の期間との比較・一文の結論・内訳は、取得したデータから機械的に算出した参考情報です。当社は、それに基づくユーザーの判断や結果について責任を負いません。
  6. デモで表示されるアプリ・国・数値は架空のものです。

第5条（データの取り扱い）

  1. 本アプリにおける情報の取り扱いは、プライバシーポリシーに定めるとおりです。
  2. 当社は、端末の故障・紛失・初期化・OS の更新・本アプリの削除等によるデータの消失について、当社の故意または重過失による場合を除き、責任を負いません。売上レポートは、再度接続することで Apple から取り直せます（Apple に日次のレポートが残っている期間に限ります）。
