Revenue for App Store Connect

提供：みやじんプロダクト

プライバシーポリシー

最終更新日：2026年10月25日 · English

みやじんプロダクト（以下「当社」）は、iOS アプリ「Revenue for App Store Connect」（以下「本アプリ」）における情報の取り扱いについて、以下のとおり定めます。

本アプリは当社のサーバーを持たず、アカウントの登録もありません。App Store Connect の API キーはお使いの端末のキーチェーンにだけ保存し、売上レポートはお使いの端末から Apple へ直接問い合わせて取得し、端末の中にだけ保存します。当社が API キーや売上データを受け取ることはありません。

1. 取り扱う情報

  1. App Store Connect の API キー：ユーザーが入力した Issuer ID・Key ID・秘密鍵（.p8）と、Vendor Number。Apple の API への問い合わせに署名するために使い、端末のキーチェーンに保存します（この端末だけで使える設定で保存し、iCloud キーチェーンには同期しません）。
  2. 売上レポート：Apple の App Store Connect API（売上レポート・日次の概要）から取得する、ユーザーご本人のアプリの日ごとのダウンロード数・再ダウンロード数・アップデート数・App 内課金・受取額（推定）・通貨・国・アプリ名・SKU・App Store の ID 等。購入者を特定できる情報は含まれません。
  3. アカウントの識別：どのアカウントのデータかを見分けるため、Issuer ID を元に戻せない形（SHA-256 のハッシュ値）にしたものと Vendor Number を、端末内に保存します。
  4. アプリのアイコン画像：売上レポートに載っている公開中のアプリのアイコン画像を、表示のために端末内に保存します（4 章）。
  5. 設定情報：表示通貨、外観（ライト・ダーク）、取得の状態（日ごとに取得できたかどうか）等は端末内にのみ保存します。
  6. 広告識別子等：広告配信のため、広告事業者が IDFA（広告識別子）や端末・利用に関する情報を取得する場合があります（5 章）。

本アプリは、氏名・メールアドレス・位置情報の入力や取得を求めません。

2. 利用目的

取得した情報は、(a) 売上レポートの取得・保存・表示・集計・分析（前の期間との比較、国別・アプリ別・種類別の内訳など）、(b) 別のアカウントのデータが混ざらないようにするための確認、(c) 不具合の改善、(d) 広告の配信・最適化・効果測定、のために利用します。

3. データの保存場所

情報保存場所
API キー（Issuer ID・Key ID・秘密鍵・Vendor Number）端末のキーチェーン（この端末だけ）
売上レポート・取得の状態端末内（本アプリ専用の領域）
アカウントの識別（Issuer ID のハッシュ値・Vendor Number）・設定情報端末内
アプリのアイコン画像端末内

当社のサーバーへの送信・保存は行いません。本アプリは iCloud による同期を行いませんが、端末のバックアップ（iCloud バックアップ等）を有効にしている場合、端末内の売上データ等がバックアップに含まれることがあります（API キーは、この端末だけで使える設定で保存しているため、別の端末へは戻りません）。

4. 外部への送信

本アプリは、機能の提供に必要な範囲で、端末から次の事業者へ直接通信します。

  1. Apple（App Store Connect API）：売上レポートを取得するため、端末で API キーを使って署名した問い合わせ（Vendor Number と日付を含みます）を Apple へ送ります。秘密鍵そのものは送りません。
  2. Apple（iTunes の検索 API）：アプリのアイコン画像を表示するため、公開中のアプリの App Store の ID と国のコードだけを送り、アイコン画像を受け取ります。API キーや売上データは送りません。
  3. Google AdMob：広告配信のため、広告識別子等が送信される場合があります（5 章）。API キーや売上データを広告事業者へ送ることはありません。

デモ（架空のデータ）を表示している間は、上記 1・2 の通信を行いません。広告（3）はデモでも表示します。当社は、法令に基づく場合を除き、取得した情報を第三者へ販売・提供しません。

5. 広告・トラッキング（ATT）

  1. 本アプリは、Google AdMob によるバナー広告を、本物のデータとデモの画面の下部に表示します。最初の画面・接続の案内には表示しません。
  2. iOS のトラッキング許可（ATT）において許可された場合、パーソナライズ広告のために広告識別子（IDFA）が利用されることがあります。許可しない場合でも、非パーソナライズ広告が表示され、本アプリはご利用いただけます。
  3. 広告の効果測定のため SKAdNetwork 等の仕組みが利用される場合があります。
  4. EEA・英国等の対象地域では、Google の同意管理プラットフォーム（UMP）による同意フォームを表示し、同意が得られるまで広告を要求しません。同意の内容は、本アプリの「マイページ」→ 右上のメニュー →「広告のプライバシー設定」からいつでも変更できます。
  5. 広告の配信に、API キーや売上データを使うことはありません。

6. 利用する第三者サービス

  • Apple（App Store Connect API、iTunes の検索 API）
  • Google AdMob（広告配信）／Google ユーザーメッセージングプラットフォーム（同意管理）

各社の取り扱いについては、それぞれのプライバシーポリシーをご確認ください（Apple プライバシーポリシー／Google プライバシーポリシー／Google 広告ポリシー）。

7. データの保持・削除

  1. 接続の解除：本アプリの「マイページ」→ 右上のメニューから接続を解除すると、端末のキーチェーンから API キーを削除します。取得済みの売上データは端末内に残り、引き続き表示できます。
  2. 別のアカウントでの接続：別のアカウントの API キーで接続し直す場合は、確認のうえ、以前のアカウントの取得済みデータを端末から削除します。
  3. アプリの削除：売上データ・設定・アイコン画像は、本アプリの削除により端末から消去されます。本アプリを入れ直した最初の起動では、キーチェーンに残った API キーも削除します。消去したデータを当社が復元することはできません（売上レポートは、再度接続することで Apple から取り直せます。Apple に日次のレポートが残っている期間に限ります）。
  4. API キーの無効化：本アプリを使わずに、App Store Connect の「ユーザとアクセス」→「統合」から、いつでも API キーを無効にできます。無効にした鍵では、本アプリも売上レポートを取得できなくなります。

8. ユーザーの権利

お住まいの地域の法令（EU・英国の一般データ保護規則〈GDPR〉、米国カリフォルニア州の消費者プライバシー法〈CCPA〉等）に基づき、ご自身の情報へのアクセス・訂正・削除・利用停止などを求める権利があります。当社はユーザーの情報をサーバーに保持していないため、端末内の情報は接続の解除や本アプリの削除で消去できます。広告事業者が取得する情報については、上記の同意設定のほか、各事業者の案内をご確認ください。当社は個人情報を販売しません。ご不明な点は 13 章の窓口へお問い合わせください。

9. 国外へのデータ移転

Apple・Google の各サービスの利用に伴い、情報が日本国外で処理される場合があります。

10. 安全管理措置

当社は、取り扱う情報の漏えい・滅失・毀損の防止のため、合理的な安全管理措置を講じます。API キーは端末のキーチェーンに保存し、秘密鍵・売上の内容を記録（ログ）に残しません。通信はすべて暗号化（HTTPS）して行います。

11. 子どものプライバシー

本アプリは13歳未満の方を対象としていません。

12. 本ポリシーの変更

当社は、必要に応じて本ポリシーを変更できます。重要な変更は本アプリ等で通知します。
